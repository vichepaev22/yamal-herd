# Тестирование

## Автоматические
```bash
make verify            # scripts/verify.py
make size              # scripts/size-report.sh
node test/smoke.mjs    # Playwright (опционально)
```
`verify.py` проверяет: баланс скобок во всех inline `<script>`; что каждый `$('id')`
существует в разметке; что уровней 31 (id 0..30 без пропусков); что суммы
`deliveryPattern` равны `count`; что максимум оленей ≤ 26; наличие обязательных
систем (Engine, InputController, dog FSM, radar-трансформ, конфиги, save-миграция);
PWA/SEO/safe-area/touch-action/noscript; наличие файлов репозитория.

## Симуляционные (выполнены на порте логики)
- HerdManager: максимальное смещение оленя за кадр ≤ 0.57 м → телепортов нет, NaN = 0.
- Инварианты собаки на L11 / L17 / L24 / L26 / L30: все уровни завершаются
  (8/8, 14/14, 18/18, 20/20, 26/26); `DELIVERED` никогда не становится целью;
  одновременно отвлечён ≤ 1 олень; 0 выходов за bounds; отвлечённый олень
  повторно собирается.
- Delivery: over-delivery (5 при минимуме 2) засчитывается и не наказуется;
  `curMin()` ≤ остатка оленей → soft-lock невозможен.
- Ввод/радар: W/S/A/D + 4 диагонали; стрелка heading на 0/45/90/180/270°.
- Radar pulse: плавный 0→1→0, ~54 % времени видим.

## Ручной чек-лист
**Мир**: центр карты → нет края; все 4 границы → тундра продолжается; вниз экрана →
нет чёрных полос; максимальный zoom-out при длинном стаде → viewport заполнен.
**Стадо**: подбор 1-го; 10 подряд; круг; S-образное движение; диагонали; цепочка не
зеркалится. **Доставка**: часть стада → счёт растёт → повторный выход → все → победа →
звёзды → следующий уровень. **Регрессия**: меню, выбор персонажа, развитие, ягоды,
Child Mode (0+1=1, 1+1=2, 2+1=3, 4+3=7), пауза, рестарт, сохранение после reload.
**Mobile**: джойстик во все стороны, отпускание = остановка, страница не скроллится,
мультитач (джойстик + кнопка), portrait/landscape, safe-area.
